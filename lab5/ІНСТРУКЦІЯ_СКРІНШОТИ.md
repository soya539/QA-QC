# Как получить все 12 скриншотов для протокола лабораторной №5

Используй **Windows 10/11**, VS Code, Git Bash/PowerShell и браузер. Скриншот области экрана: **Win + Shift + S** → выделить → вставить `Ctrl+V` в DOCX вместо символа `—` над нужной подписью. Лучше сохранять отдельным PNG с соответствующим номером в свою папку `screenshots/`, которую можно создать рядом с `README.md`.

**Перед началом:** открой `lab5-unit-integration-tests` в VS Code → Terminal → New Terminal. Введи `node -v`, `npm -v`, затем `npm install`. Для `npm test` интернет не нужен после установки пакетов. В архиве предусмотрено **11 тестов в 8 файлах**, включая **3 unit + 2 integration** по настоящему To-Do приложению лабораторной №1.

## Рисунок 1. Структура проекта

VS Code → Explorer (`Ctrl+Shift+E`). Раскрой `app`, `src`, `tests/examples`, `tests/todo/unit`, `tests/todo/integration`. Убедись, что видны `package.json` и `jest.config.js`. Для компактного вида можно сделать два снимка и выбрать самый полный.

## Рисунок 2. Демонстрационные тесты из методички (4 suites / 6 tests)

В каталоге проекта запусти `npm run test:examples`. Дождись завершения и сними терминал так, чтобы было видно **4 passed, 4 total** и **6 passed, 6 total**. Не надо удалять остальные тесты: команда запускает только примеры.

## Рисунок 3. Общий запуск (8 suites / 11 tests)

Запусти `npm test`. На снимке должны быть перечислены `PASS` и внизу **8 suites / 11 tests**. Если есть ошибки, сначала исправь их, а уже потом фиксируй результат; не подставляй изображение с выдуманными успехами.

## Рисунок 4. Создание проекта в Testomat.io

Открой https://app.testomat.io/projects/new. Войди/зарегистрируйся, выбери **Classical**, название `QA-QC Lab5 ToDo`; снимай форму ДО Create. При необходимости выбери бесплатный тариф.

## Рисунок 5. Import Tests from Source Code

После создания проекта открой **Import Tests from Source Code** (текст кнопки может немного отличаться). Выбери **Jest**, **JavaScript** и **Windows** (или Git Bash, если сайт предлагает). Покажи настройки на скрине. Секретный ключ `TESTOMATIO` или токен импорта в скриншоте **обязательно закрой чёрным прямоугольником** или обрежь.

## Рисунок 6. Терминал после импорта

На странице Testomat.io нажми Copy команды импорта, вставь её в терминал, открытый в папке проекта. Сделай скрин после успешного импорта с количеством **11 tests found** и сообщением об отправке. Если сервис показывает другое количество, проверь, какой glob-шаблон он нашёл. Ключ в самой команде замаскируй.

## Рисунок 7. Список импортированных тестов

В браузере обнови Testomat.io (F5), открой **Tests / Suites**. Покажи список названий тестов и их количество **11**. Если в интерфейсе много групп, раскрой ветку с To-Do тестами.

## Рисунок 8. Страница настройки отправки результатов

Открой Testomat.io → **Runs** → настройку automated tests / reporting. На скриншоте должны быть видны раздел с Jest и инструкции для репортера. Ключ закрыть.

## Рисунок 9. Запуск с репортёром Testomat.io

В терминале проекта один раз установи репортер: `npm i --save-dev @testomatio/reporter`. Проверь `jest.config.js`. После этого:

**Git Bash**:
```bash
TESTOMATIO='ВАШ_КЛЮЧ' npm test
```
**PowerShell**:
```powershell
$env:TESTOMATIO = 'ВАШ_КЛЮЧ'
npm test
Remove-Item Env:TESTOMATIO
```

Сними вывод тестов и строки передачи результатов. **Ключ закрой**, лучше снять нижнюю часть окна без введённой команды.

## Рисунок 10. Список Test Runs

Обнови Testomat.io → **Runs**, покажи новый запуск после `npm test`, дату и статистику прошедших тестов. Если данные не появились, проверь ключ и настройки репортера. Скрин должен отражать реальный результат.

## Рисунок 11. Детальный Test Run

Открой запуск из рисунка 10. На снимке нужны диаграмма/проценты Passed и названия тестов (если интерфейс позволяет). В случае Fail приложи настоящую статистику и исправь/допиши анализ.

## Рисунок 12. GitHub-репозиторий

В локальном репозитории `QA-QC` создай ветку `lab5` при необходимости, добавь папку `lab5/` с **содержимым** распакованной `lab5-unit-integration-tests` (например, `QA-QC/lab5/package.json`), выполни `git add lab5`, `git commit -m "Add Jest tests for lab5"`, `git push -u origin lab5`. Открой веб-страницу своей ветки с содержимым папок `app`, `src`, `tests`, `package.json`. В протоколе замени `—` в строке «Посилання на GitHub» настоящим URL ветки/папки.

## Что нужно заменить в документе после работы

1. Вставить 12 собственных скриншотов над подписями «Рисунок 1» … «Рисунок 12».
2. Указать настоящую дату выполнения.
3. Вставить итоговую ссылку на ветку/папку GitHub.
4. По результату реальных запусков обновить в таблице статусы `Очікується` → `Passed` или `Failed`, а также раздел «Висновок».
5. По возможности указать URL проекта Testomat.io (не ключ) и дату последнего Test Run.

**Никогда не присылай мне API-ключ Testomat.io, пароль, токен доступа или cookies.**
